```json
}
```

**实际响应**:
```json
{
  "success": false,
  "error": "提取失败"

```

**原因分析**:
- 测试输入内容过于简单，无法被LLM识别为有效的招标文档

- 这是预期行为，提取功能需要完整的招标文档内容

**建议**:
- 可优化错误提示，区分"文档内容不足"和"解析失败"
- 建议前端提示用户上传完整的招标文档
