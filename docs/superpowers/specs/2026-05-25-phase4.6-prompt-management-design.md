## 1. 概述

### 1.1 背景

Phase 4.5 已完成招标文件解析引擎，产出 `ParsedDocument → TenderChunk → TenderRequirement` 结构化数据。Phase 4.6 需要建立 AI 提示词与模型调用基础设施，为后续 `outline`、`generation`、`requirements`、`knowledge` 等 app 提供统一的 AI 能力支撑。

### 1.2 目标

建立可版本化、可审计、可复用的 AI 提示词与模型调用基础设施：

- **提示词模板管理**：模板库、版本化、变量插值、Schema 校验
- **LLM 调用封装**：Provider 抽象、模型配置、重试策略、Token 计费
- **调用审计**：完整记录每次调用的输入输出、Token 消耗、耗时

### 1.3 核心设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 模板版本化 | PromptTemplate + PromptVersion | 支持版本回滚、A/B 测试、审计复现 |
| 模板作用域 | system / tenant / project / user | 分层管理，P0 先实现 system |
| 模板解析优先级 | project > tenant > user > system | 项目级覆盖企业级，企业级覆盖系统级 |
| Provider 抽象 | 统一 LLMService + ProviderClient | 支持多供应商切换，Mock 打通流程 |
| 调用日志 | PromptRun 完整记录 | 审计、复现、Token 统计、错误追溯 |
| 输出格式 | 分析类 JSON，正文类 Markdown | 结构化输出便于后续流程处理 |
| Jinja2 渲染 | SandboxedEnvironment + StrictUndefined | 安全沙箱 + 变量缺失报错，避免生成缺字段内容 |

### 1.4 MVP 边界

**P0（核心）：**
- PromptTemplate、PromptVersion 模型
- ModelProvider、ModelConfig 模型
- PromptRun 调用日志模型
- PromptRenderService 渲染服务（SandboxedEnvironment + StrictUndefined）
- LLMService 抽象 + MockLLMClient
- PromptExecutionService 执行服务
- output_schema 服务端校验
- PromptVersion 最小发布机制（draft → published）
- 内置 3 个默认 Prompt（大纲生成、条款分析、章节撰写）

**P1（后续）：**
- BailianClient 真实调用
- PromptVersion 归档、回滚、发布审批、版本对比
- Prompt 测试运行接口
- 项目级 Prompt 覆盖
- Token 消耗统计页面

**P2（后续）：**
- 企业级/用户级模板
- Prompt A/B 测试、多模型对比
- RAG 上下文自动组装
- Embedding/Rerank 统一配置
- PromptRun 敏感信息脱敏和访问控制

### 3.1 PromptTemplate（提示词模板）

管理提示词模板的逻辑身份，一个模板可有多个版本。

```python
class PromptScope:
    """模板作用域。"""

    SYSTEM = "system"
    TENANT = "tenant"
    PROJECT = "project"
    USER = "user"

    CHOICES = [
        (SYSTEM, "系统级"),
        (TENANT, "企业级"),
        (PROJECT, "项目级"),

class PromptTemplate(TimeStampedModel):
    """提示词模板。"""

    )
    name = models.CharField(

        "场景",
        max_length=64,
        choices=PromptScenario.CHOICES,
    )
    description = models.TextField(
        "描述",
        blank=True,
    )
    scope = models.CharField(
        "作用域",
        max_length=32,
        choices=PromptScope.CHOICES,
        default=PromptScope.SYSTEM,
    )
    project = models.ForeignKey(
        "projects.Project",
        on_delete=models.CASCADE,
        null=True,
        blank=True,
        verbose_name="项目",
    )
    is_active = models.BooleanField(
        "是否启用",
        default=True,
    )

    class Meta:
        db_table = "prompt_template"
        verbose_name = "提示词模板"
        verbose_name_plural = "提示词模板"
        constraints = [
            # P0 暂不支持同 key 多 scope 覆盖
            # P1 引入模板解析优先级后改为复合唯一约束
            models.UniqueConstraint(
                fields=["key", "scope", "project"],
                name="uniq_prompt_template_scope_project_key",
                condition=models.Q(project__isnull=False),
            ),
            models.UniqueConstraint(
                fields=["key", "scope"],
                name="uniq_prompt_template_scope_key",
                condition=models.Q(project__isnull=True),
            ),
        ]
        indexes = [
            models.Index(fields=["scenario"]),
            models.Index(fields=["scope"]),
        ]

    def __str__(self):
        return f"{self.key} ({self.scenario})"
```

**作用域说明：**

| 作用域 | 说明 | P0 支持 |
|--------|------|---------|
| system | 系统内置模板，管理员维护 | ✅ |
| tenant | 企业级模板，统一风格 | ❌ P2 |
| project | 项目级模板，针对项目微调 | ❌ P1 |
| user | 个人模板 | ❌ P2 |

**模板解析优先级：**

```
project > tenant > user > system
```

当同一 `key` 存在多个作用域版本时，优先使用项目级，其次企业级，再次用户级，最后系统级。

```python
def resolve_template(template_key: str, project=None, tenant=None, user=None) -> PromptTemplate:
    """解析模板，按优先级查找。

    P0: only system scope
    P1/P2: project > tenant > user > system
    """
    # P0 只支持 system
    return PromptTemplate.objects.get(
        key=template_key,
        scope=PromptScope.SYSTEM,
        is_active=True,
    )
```

```python
class PromptVersionStatus:
    """版本状态。"""

    DRAFT = "draft"
    PUBLISHED = "published"
    ARCHIVED = "archived"

    CHOICES = [
        (DRAFT, "草稿"),

class PromptVersion(TimeStampedModel):

        verbose_name="模板",

        "版本号",
        max_length=32,
    )
    system_prompt = models.TextField(
        "系统提示词",
        blank=True,
    )
    user_prompt = models.TextField(
        "用户提示词",
    )
    output_schema = models.JSONField(
        "输出 Schema",
        default=dict,
        blank=True,
        help_text="JSON Schema 定义期望输出结构",
    )
    variable_schema = models.JSONField(
        "变量 Schema",
        default=dict,
        blank=True,
        help_text="JSON Schema 定义输入变量结构",
    )
    status = models.CharField(
        "状态",
        max_length=16,
        choices=PromptVersionStatus.CHOICES,
        default=PromptVersionStatus.DRAFT,
    )
    changelog = models.TextField(
        "变更说明",
        blank=True,
    )
    created_by = models.ForeignKey(
        settings.AUTH_USER_MODEL,
        on_delete=models.SET_NULL,
        null=True,
        blank=True,
        verbose_name="创建人",
    )

    class Meta:
        db_table = "prompt_version"
        verbose_name = "提示词版本"
        verbose_name_plural = "提示词版本"
        constraints = [
            models.UniqueConstraint(
                fields=["template", "version"],
                name="uniq_prompt_version",
            ),
            # 一个模板只能有一个 published 版本
            models.UniqueConstraint(
                fields=["template"],
                condition=models.Q(status=PromptVersionStatus.PUBLISHED),
                name="uniq_published_prompt_version_per_template",
            ),
        ]
        indexes = [
            models.Index(fields=["template", "status"]),
        ]

    def __str__(self):
        return f"{self.template.key}@{self.version} ({self.status})"

    def publish(self) -> None:
        """发布版本（事务保护）。"""
        with transaction.atomic():
            # 将当前 published 版本改为 archived
            PromptVersion.objects.filter(
                template=self.template,
                status=PromptVersionStatus.PUBLISHED,
            ).update(status=PromptVersionStatus.ARCHIVED)

            # 发布当前版本
            self.status = PromptVersionStatus.PUBLISHED
            self.save(update_fields=["status"])
```

**关键约束：**
- 同一模板同一版本号唯一
- 一个模板只能有一个 `published` 版本（DB 约束）
- `output_schema` 为空时表示自由文本输出，非空时要求 JSON 输出并校验

## 4. 服务设计

### 4.1 PromptRenderService（渲染服务）

负责变量插值和 Schema 校验。使用 **SandboxedEnvironment + StrictUndefined** 确保安全和变量缺失报错。

```python
from jinja2.sandbox import SandboxedEnvironment
from jinja2 import StrictUndefined


class PromptRenderService:
    """提示词渲染服务。"""

    def __init__(self):
        # 使用安全沙箱 + 严格未定义变量检查
        self._env = SandboxedEnvironment(undefined=StrictUndefined)

    def render(
        self,
        prompt_version: PromptVersion,
        variables: dict,
    ) -> RenderedPrompt:
        """渲染提示词。

        Args:
            prompt_version: 提示词版本
            variables: 输入变量

        Returns:
            RenderedPrompt(system_prompt, user_prompt)

        Raises:
            VariableValidationError: 变量校验失败
            TemplateRenderError: 模板渲染失败（如变量缺失）
        """
        # 1. 校验变量 Schema
        if prompt_version.variable_schema:
            self._validate_variables(prompt_version.variable_schema, variables)

        # 2. 渲染模板
        try:
            system_prompt = self._render_text(
                prompt_version.system_prompt,
                variables,
            )
            user_prompt = self._render_text(
                prompt_version.user_prompt,
                variables,
            )
        except Exception as exc:
            # StrictUndefined 会在变量缺失时抛出异常
            raise TemplateRenderError(f"模板渲染失败: {exc}")

        return RenderedPrompt(
            system_prompt=system_prompt,
            user_prompt=user_prompt,
        )

    def _render_text(self, template: str, variables: dict) -> str:
        """使用 Jinja2 SandboxedEnvironment 渲染模板。"""
        if not template:
            return ""
        tmpl = self._env.from_string(template)
        return tmpl.render(**variables)

    def _validate_variables(self, schema: dict, variables: dict) -> None:
        """校验变量是否符合 Schema。"""
        import jsonschema
        try:
            jsonschema.validate(variables, schema)
        except jsonschema.ValidationError as exc:
            raise VariableValidationError(str(exc))
```

```python
        """执行对话调用。

        Args:
            model_config: 模型配置
            system_prompt: 系统提示词
            user_prompt: 用户提示词
            response_format: 响应格式（JSON Schema）

        Returns:
            LLMResponse(text, json, tokens, latency)
        """
        provider = self._providers.get(model_config.provider.provider_type)
        if not provider:
            raise ProviderNotFoundError(model_config.provider.provider_type)

        return provider.chat(
            model_config=model_config,
            system_prompt=system_prompt,
            user_prompt=user_prompt,
            response_format=response_format,
        )
```

### 4.4 PromptExecutionService（执行服务）

组合渲染、调用、日志记录。**output_schema 非空时进行服务端校验**。

```python
import json
import jsonschema
import time


class OutputValidationError(Exception):
    """输出校验失败。"""
    pass


class PromptExecutionService:
    """提示词执行服务。"""

    def __init__(self):
        self.render_service = PromptRenderService()
        self.llm_service = LLMService()

    def execute(
        self,
        template_key: str,
        variables: dict,
        model_config: ModelConfig | None = None,
        context: dict | None = None,
    ) -> PromptRun:
        """执行提示词。

        Args:
            template_key: 模板键
            variables: 输入变量
            model_config: 模型配置（可选，默认使用场景默认配置）
            context: 业务上下文（project、tender_file 等）

        Returns:
            PromptRun 运行记录
        """
        # 1. 获取已发布版本
        prompt_version = self._get_published_version(template_key)

        # 2. 渲染提示词
        rendered = self.render_service.render(prompt_version, variables)

        # 3. 确定模型配置
        if model_config is None:
            model_config = self._get_default_model_config()

        # 4. 创建运行记录
        run = PromptRun.objects.create(
            prompt_template=prompt_version.template,
            prompt_version=prompt_version,
            model_config=model_config,
            scenario=prompt_version.template.scenario,
            input_variables=variables,
            rendered_system_prompt=rendered.system_prompt,
            rendered_user_prompt=rendered.user_prompt,
            status=PromptRunStatus.RUNNING,
            **(context or {}),
        )

        # 5. 执行调用
        start_time = time.time()
        try:
            response = self.llm_service.chat(
                model_config=model_config,
                system_prompt=rendered.system_prompt,
                user_prompt=rendered.user_prompt,
                response_format=prompt_version.output_schema or None,
            )

            # 6. 校验输出 Schema
            if prompt_version.output_schema:
                self._validate_output(response.json, prompt_version.output_schema)

            # 7. 更新成功结果
            run.output_text = response.text
            run.output_json = response.json
            run.prompt_tokens = response.prompt_tokens
            run.completion_tokens = response.completion_tokens
            run.total_tokens = response.total_tokens
            run.latency_ms = int((time.time() - start_time) * 1000)
            run.status = PromptRunStatus.SUCCEEDED
            run.save()

        except OutputValidationError as exc:
            # 输出校验失败
            run.status = PromptRunStatus.FAILED
            run.error_message = f"输出 JSON 不符合 schema: {exc}"
            run.latency_ms = int((time.time() - start_time) * 1000)
            run.save()
            raise

        except Exception as exc:
            # 8. 记录失败
            run.status = PromptRunStatus.FAILED
            run.error_message = str(exc)[:2000]
            run.latency_ms = int((time.time() - start_time) * 1000)
            run.save()
            raise

        return run

    def _validate_output(self, output_json: dict, schema: dict) -> None:
        """校验输出是否符合 Schema。"""
        try:
            jsonschema.validate(output_json, schema)
        except jsonschema.ValidationError as exc:
            raise OutputValidationError(str(exc))
```

## 8. 实现注意事项

### 8.1 关键约束

1. **PromptVersion 发布必须保证同一模板只有一个 published 版本**
   - 使用部分唯一约束 `uniq_published_prompt_version_per_template`
   - 发布时使用事务：先将现有 published 改为 archived，再发布新版本

2. **ModelConfig 默认模型必须保证同一 model_type 只有一个 active default**
   - 使用部分唯一约束 `uniq_default_model_per_type`
   - 设置新默认时需先清除旧默认

3. **Prompt 渲染使用 SandboxedEnvironment + StrictUndefined**
   - 安全沙箱防止模板注入
   - StrictUndefined 确保变量缺失直接报错，避免生成缺字段内容

4. **output_schema 非空时，模型输出必须经过 jsonschema 校验**
   - 服务端二次校验，不依赖模型承诺
   - 校验失败记录到 PromptRun.error_message

5. **PromptRun 应完整记录渲染后的 prompt**
   - 后续需支持敏感信息脱敏和访问控制
   - 预留 `is_sensitive` 字段

6. **template_key 解析应预留 scope 优先级**
   - 优先级：project > tenant > user > system
   - P0 只实现 system，但设计预留扩展空间

7. **P0 只实现 system scope**
   - 项目级/企业级覆盖不在本阶段
   - PromptTemplate.key 当前全局唯一，P1 改为复合唯一

8. **MockLLMClient 用于测试**
   - P0 验收边界为 Mock 调用通过
   - BailianClient 真实调用在 P1 实现
