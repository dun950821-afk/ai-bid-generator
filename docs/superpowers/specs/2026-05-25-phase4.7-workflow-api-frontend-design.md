## 1. 概述

### 1.1 背景

Phase 4.2/4.3 已完成工作流模型和服务层：
- `WorkflowTemplate`、`WorkflowNodeTemplate` - 流程模板
- `LotWorkflow`、`WorkflowNodeInstance` - 工作流实例
- `TemplateService`、`WorkflowService` - 业务服务

Phase 4.5/4.6 已完成数据处理和 AI 能力：
- 招标文件解析引擎（ParsedDocument、TenderChunk）
- 提示词管理（PromptTemplate、PromptRun）

Phase 4.7 需要补齐 API 层和前端可视化，让用户能：
- 清楚看到标书生成流程执行到哪一步
- 每个节点状态如何
- 产物是什么
- 失败后如何处理

### 1.2 目标

建立 **执行态流程画布 + 节点详情抽屉 + 产物预览 + 工作流 API**：

- **执行态优先**：P0 聚焦执行态，编辑态预留到 P1
- **语义化节点 UI**：数据型/审批型/AI型/手动型/系统型
- **状态联动抽屉**：单一状态源，画布与抽屉自动同步
- **产物预览区**：动态 Viewer，按需加载
- **轻量轮询**：状态轮询 + 详情按需加载

### 1.3 MVP 边界

**P0（核心）：**
- 执行态流程画布（Vue Flow）
- 工作流实例 API（初始化、启动、查询）
- 节点详情 API + 状态机校验
- 节点动作 API（start/retry/approve/reject）
- 节点产物 API（列表、预览、下载）
- 节点日志 API
- 5 类自定义节点 UI
- 右侧抽屉（概览/输入/产物/日志）
- MiniMap + Controls + FitView
- 3-5 秒轻量轮询

**P1（增强）：**
- 编辑模式
- 模板编辑 API
- 节点工具库
- 拖拽新增节点
- 草稿保存与发布
- 快捷搜索节点
- 状态变化 Toast
- 自动定位当前节点

**P2（高级）：**
- rollback（强制 reason + downstream artifact 策略）
- 执行回放

### 3.5 状态机校验

节点动作必须校验状态迁移合法性：

| 当前状态 | 允许的动作 |
|---------|-----------|
| `pending` | start, skip |
| `running` | complete, fail |
| `failed` | retry |
| `waiting_approval` | approve, reject |
| `completed` | - |
| `skipped` | - |
| `blocked` | - |

非法状态迁移返回 `409 Conflict`：
```json
{
  "error": "invalid_state_transition",
  "message": "节点状态为 completed，无法再次 complete",
  "current_status": "completed",
  "allowed_actions": []
}
```

```typescript
// workflowStore.ts
const workflowStore = defineStore('workflow', () => {
  // 领域数据（后端返回）
  const workflowInstance = ref<WorkflowInstance | null>(null)
  const workflowNodes = ref<WorkflowNodeInstance[]>([])
  const workflowEdges = ref<WorkflowEdge[]>([])
  
  // UI 状态
  const selectedNodeId = ref<string | null>(null)
  const isLoading = ref(false)
  
  // 轮询控制
  let pollingTimer: number | null = null
  
  // 计算属性：选中的节点
  const selectedNode = computed(() =>
    workflowNodes.value.find(n => n.id === selectedNodeId.value)
  )
  
  // 计算属性：Vue Flow 节点（渲染层）
  const flowNodes = computed(() =>
    workflowNodes.value.map(toVueFlowNode)
  )
  
  // 计算属性：Vue Flow 边
  const flowEdges = computed(() =>
    workflowEdges.value.map(toVueFlowEdge)
  )
  
  // 方法
  async function fetchWorkflow(lotId: string) { ... }
  async function fetchStatus(lotId: string) { ... }
  function startPolling(lotId: string) { ... }
  function stopPolling() { ... }
  function selectNode(id: string | null) { ... }
  async function retryNode(nodeId: string, reason: string) { ... }
  async function approveNode(nodeId: string, comment: string) { ... }
  async function rejectNode(nodeId: string, comment: string) { ... }
  function locateNode(nodeId: string) { ... }
  
  return {
    // 状态
    workflowInstance,
    workflowNodes,
    workflowEdges,
    selectedNodeId,
    isLoading,
    // 计算属性
    selectedNode,
    flowNodes,
    flowEdges,
    // 方法
    fetchWorkflow,
    fetchStatus,
    startPolling,
    stopPolling,
    selectNode,
    retryNode,
    approveNode,
    rejectNode,
    locateNode,
  }

```

**数据流：**
```
后端轮询 /status
      ↓

      ↓
workflowNodes 更新
      ↓
flowNodes computed 自动刷新
      ↓
Vue Flow 节点刷新
      ↓
```

### 4.4 轮询策略

```typescript
function startPolling(lotId: string) {
  stopPolling()
  
  const poll = async () => {
    const status = await fetchStatus(lotId)
    
    // 状态变化提示
    if (status.nodeChanged) {
      ElMessage.success(`节点已更新为"${status.newStatus}"`)
    }
    
    // 继续轮询条件
    if (status.status === 'running') {
      pollingTimer = setTimeout(poll, 3000)
    } else if (status.status === 'failed') {
      // 失败时停止轮询，用户手动重试
      stopPolling()
    }
  }
  
  poll()
}
```

**轮询频率：**
- 运行中：3-5 秒
- 全部完成：停止轮询
- 页面不可见（visibilitychange）：暂停轮询
- 用户查看失败节点：继续刷新日志

### 5.2 节点动作视图

```python
# backend/apps/workflows/views/node_views.py
class NodeActionView(APIView):
    """节点动作基类。"""
    
    def validate_state_transition(self, node, action):
        """校验状态迁移合法性。"""
        allowed = STATE_TRANSITIONS.get(node.status, [])
        if action not in allowed:
            raise ValidationError(
                f"节点状态为 {node.status}，无法执行 {action}"
            )
    
    def record_audit(self, node, action, operator, reason=None):
        """记录审计日志。"""
        WorkflowAuditLog.objects.create(
            instance_id=node.lot_workflow_id,
            node_id=node.id,
            action=action,
            previous_status=node.status,
            new_status=self.get_new_status(action),
            operator=operator,
            reason=reason,
        )


class NodeStartView(NodeActionView):
    """开始执行节点。"""
    
    def post(self, request, node_id):
        node = get_object_or_404(WorkflowNodeInstance, pk=node_id)
        self.validate_state_transition(node, 'start')
        
        # 调用服务
        WorkflowService.start_node(node, request.user)
        self.record_audit(node, 'start', request.user)
        
        return Response({
            "id": node.id,
            "status": node.status,
        })


class NodeRetryView(NodeActionView):
    """重试节点。"""
    
    def post(self, request, node_id):
        node = get_object_or_404(WorkflowNodeInstance, pk=node_id)
        self.validate_state_transition(node, 'retry')
        
        reason = request.data.get('reason', '')
        WorkflowService.start_node(node, request.user)
        self.record_audit(node, 'retry', request.user, reason)
        
        return Response({
            "id": node.id,
            "status": node.status,
        })


class NodeApproveView(NodeActionView):
    """审批通过。"""
    
    def post(self, request, node_id):
        node = get_object_or_404(WorkflowNodeInstance, pk=node_id)
        self.validate_state_transition(node, 'approve')
        
        comment = request.data.get('comment', '')
        WorkflowService.approve_node(node, request.user, comment)
        self.record_audit(node, 'approve', request.user, comment)
        
        return Response({
            "id": node.id,
            "status": node.status,
            "approval_status": node.approval_status,
        })
```
