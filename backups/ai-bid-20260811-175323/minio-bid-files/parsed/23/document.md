# 附件：安徽移动供应商合作规则

（202505）

## 1.1 安徽移动产品质量违约处理规则

# 一、本规则所称产品是指供应商（“乙方”）向安徽移动（“甲方”）提供的满足需求的有形的设备、货物或服务（以下统称“产品”）。

# 二、本规则所称产品质量问题是指乙方提供的产品由于不符合技术规范要求（包括设计、制造、运输、储存、交付、实施、售后服务等过程）给甲方带来的各类问题和风险（不包括甲方安装、使用、维护不当及不可抗力等因素）。

# 三、甲方通过开展到货验收、自检、第三方送检、飞行检测/检查、驻厂检测、现场考评等方式，对乙方提供的产品质量进行全方位监测，必要时可邀请乙方参与到货抽样、质量检测等环节监督工作。若乙方对检测结果有异议，可在收到检测结果通知后15日内向甲方书面反馈。乙方提出的异议应建立在客观事实基础上，乙方无正当理由拒不确认检测结果的，视为乙方同意甲方检测结果。

# 四、对于质量不合格/有缺陷、部件存在缺失的问题产品，供应商应立即无条件更换或者补齐，包括所有已建/已用、在建/在用、已采购未建/未用的同种型号产品，由此引发的相关费用由供应商免费承担（包括但不限于产品更换补齐过程中发生的拆除、安装、仓储、物流等相关费用）。供应商应在规定的时限内完成产品更换补齐工作。

# 五、对于已建/已用、在建/在用且无法更换的问题产品，由双方协商解决方案，包括但不限于采取延长质保期限、寻求经济补偿等方式。

（一）产品检测结果判定不合格，甲方可按照问题产品金额100%向乙方寻求经济补偿；

（二）产品检测结果判定有缺陷，甲方可按照问题产品金额30%向乙方寻求经济补偿；

（三）产品部件出现缺失，甲方可按照问题产品缺失部件金额100%向乙方寻求经济补偿；

（四）检测结果判定不合格或有缺陷产品，检测数值如满足采购技术规范标准（不满足供应商应答结果），经济补偿标准可在上述基础上再减半执行。

# 六、根据供应商质量违约情形，安徽移动将追究供应商相应的违约责任，向供应商收取质量违约金：

（一）供应商有下列情形之一的，属于一般质量违约情形

1.产品检测结果判定为合格，但出现缺陷指标。

2.供应商未按照框架协议或合同要求提供完整的产品，出现产品非关键部件缺失。

3.其他经安徽移动认定为一般质量违约情形的。

（二）供应商有下列情形之一的，属于严重质量违约情形

1.产品检测结果判定为不合格。

2.产品检测结果判定为合格但有缺陷指标，经甲方需求主管部门牵头鉴定，产品缺陷对安徽移动网络运行、安全生产存在严重问题隐患。

3.供应商未按照框架协议或合同要求提供完整的产品，出现产品关键部件缺失。

4.产品未开展质量检测，但供应商故意降低产品质量标准，被甲方需求单位或者第三方投诉且经核实后确认投诉有效。

5.其他经安徽移动认定为严重质量违约情形的。

（三）供应商有下列情形之一的，属于特别严重质量违约情形

1.因为供应商产品质量问题造成安徽移动网络故障，或者造成安徽移动发生安全生产事故，或者对安徽移动造成其他较大负面影响。

2.检测过程中，供应商违规替换检测样品、与检测单位串通伪造检测结果、向采购人或检测单位等相关方及相关人员行贿或违法违规提供不正当利益。

3.其他经安徽移动认定为特别严重质量违约情形的。

（四）各类情形对应的质量违约金收取标准如下：

1.出现一般质量违约情形，可处以问题产品金额10%质量违约金。

2.出现严重质量违约情形，可处以问题产品金额20%质量违约金。

3.出现特别严重质量违约情形，可处以问题产品金额30%质量违约金。

（五）供应商出现以下情形，可在上述第（四）项规定的各项标准基础上提高质量违约金收取比例：

1.供应商未积极主动配合处理产品质量问题的；同一集采周期内供应商再次出现质量违约情形被追究责任的。质量违约金标准可增加10%执行；

2.供应商在质量问题处理过程中，出现有意隐瞒或谎报与产品质量相关信息的；供应商对存在的产品质量问题拒不整改的，包括拒不签署质量问题约谈处理记录、拒不缴纳质量违约金、拒不进行退换货；同一集采周期内出现3次及以上质量违约情形被追究责任的。质量违约金标准可增加20%执行。

（六）供应商积极主动发起问题产品召回且承担召回过程中涉及的所有相关费用，经安徽移动评估未造成影响的，可免于追究质量违约责任。

（七）问题产品金额按照对应合同或订单中产品实际到货金额进行认定，为含税金额。

（八）供应商出现产品质量违约情形时，如造成安徽移动重大经济损失。质量违约金不足以弥补安徽移动损失的，安徽移动有权进一步追偿。

# 七、供应商出现质量违约情形时，根据具体违约情况及其严重性，安徽移动除收取质量违约金外，还可选择暂停付款、调整份额、限期整改、暂停、终止供货资格、上报集团公司处理、后评估扣分、禁止合作等处罚方式。上述处罚方式可以视情节情况单独使用，也可以综合使用。

# 八、质量问题处理期间，甲方有权暂停乙方合同款项支付，直至问题处理完毕。甲方有权从支付给乙方的合同款项中扣除其应缴纳的质量违约金。

# 九、规则应用说明

本规则作为甲乙双方签订的框架协议或合同附件组成部分，与合同正文有同等法律效力。框架协议或合同正文中如对产品质量违约处理涉及的经济补偿金额或违约金金额有明确可计算的标准，则按照框架协议或合同正文规定执行。

# 十、其他

产品质量问题发现之日起往前3年内（按照检测结果报告日期或者收到质量问题投诉日期开始计算），供应商未发生过同类产品质量不合格问题，且积极配合问题整改和违约追责，对安徽移动生产运营、业务发展等未造成实质性影响，可不作一般负面行为认定，经安徽移动内部决策后实施。

## 1.2 安徽移动供应商绩效评估处理规则

# 一、供应商绩效评估是指甲方（安徽移动）根据既定的标准、流程对乙方（供应商）在一定期间内各方面的合作表现所进行的综合评价与管理工作。

# 二、评估标准原则上覆盖乙方（供应商）在签约、交付、建设、维护/使用直至退出的全过程中的技术、交付、质量、服务等方面的综合表现。

# 三、评估周期可结合产品和服务特点按照不同周期定期组织，综合考虑乙方（供应商）所提供货物、工程、服务的使用稳定性、技术成熟度、评估复杂性、生命周期时长、评估工作量等因素，一般以年度为周期。特殊情况下，也可在固定周期之外组织专项评估活动。

- 四、乙方（供应商）绩效评估结果得分由例行评估结果和综合加减两个部分组成。例行评估是指甲方（安徽移动）省公司各相关部门和各市分公司评分结果汇总；综合加减根据供应商在全省的质量、履约等方面的综合表现，在例行评估结果上进行加减，具体如下：

- 加分的情形包括：

- 1.对我公司生产、经营、管理做出重大贡献的；

- 2.行业紧缺或战略产品供货表现良好或给予重大支持，并得到我公司认可的；

- 3.对于我方紧急供货要求予以积极配合，快速到货，确保我方及时完成相关工作，并得到我公司认可的；

- 4.在遇到抢险救灾等突发事件时，能协助我公司完成设备紧急调拨、包装、运输等工作，并得到我公司认可的；

- 5.积极响应我公司号召参与乡村振兴、慈善事业或其他履行社会责任事项，并得到我公司认可的。

- 6.与我公司政企业务深入合作，并取得实际成效的等；

- 减分的具体情形包括：

- 1.合同签订后或框架订单下达后，拒绝供货或提供服务，被使用单位书面有效投诉；

- 2.因供应商原因，到货慢或服务差（如安装不及时、维修不及时等），达不到合同约定，被使用单位书面有效投诉的；

- 3.施工、物业等服务类产品不符合合同要求（如人员配置、人员能力、服务工期等），被使用单位书面有效投诉的；

- 4.在产品到货检测（含设计审查）或使用（含施工）过程中，发现产品质量问题；

- 5.供应商出现严重违约、重大质量问题、安全事件以及其他供应商负面行为造成公司生产经营活动受到严重影响或带来其它恶劣影响，且并被经济处罚或被列入严重负面行为的等。

- 6.供应商发生经营状况重大变化以及重要担保、重大合同纠纷或诉讼、信用等级和资质变化等可能影响履约能力的重大事项，未及时向我公司提供书面通知，因而造成后期采购行为无法履约或造成损失的；

- 7.供应商发生名称和帐号变更，未及时通知我公司，导致我公司存在支付风险的情况；

- 8.在供应商信息核查后，对供应商申报信息组织抽查中发现问题情节轻微，对我方未造成负面影响的；

- 五、对于质量、交付、服务出现问题的供应商原则上相关评分项的得分不高于未出现问题的供应商。

# 六、乙方供应商绩效评估结果如低于70分，将要求乙方（供应商）递交针对性整改计划；绩效评估结果如低于60分，可取消其省内供货资格，并在合同规定范围内进行索赔。如为一级集采供应商，评估情况上报集团；若为二级集采供应商，可按照《中国移动通信集团安徽有限公司供应商负面行为管理办法》中严重负面行为或特别严重负面行为进行责任追究。

# 七、乙方的供应商绩效评估结果通过安徽移动供应商门户一对一向乙方（供应商）发布，将作为甲方（安徽移动）供应商选择、份额分配、供应商分级和奖惩、集采供应商推荐等工作的重要依据。

# 八、乙方（供应商）在禁止合作期满后参与安徽移动相应产品类别采购活动时，其首次参与时的绩效评估成绩按照新供应商取定标准计取。

## 1.3 安徽移动供应商分级管理规则

(一)甲方（安徽移动）集采供应商分级评定原则上每年按产品开展，并根据乙方（供应商）的负面行为、乙方（供应商）潜在风险评估等情况变化动态调整供应商分级结果。

(二)甲方（安徽移动）集采供应商分级主要评估乙方（供应商）的日常履约（绩效评估）、综合实力、合作规模以及等方面表现。

(三)按照不同的产品，甲方（安徽移动）集采供应商分级的级别分为A、B、C、D四个等级，其中：

1.A级供应商为优秀供应商。

2.B级供应商为良好供应商。

3.C级供应商为合格供应商。

4.D级供应商为不合格供应商。

根据乙方（供应商）产品分级结果，对乙方（供应商）实施相应的管理措施。给予优质供应商激励并开展长期稳定合作，对于分级评估不佳的供应商实施惩罚和退出机制。

（四）对于A级供应商可选用以下管理措施：

1.可根据供应商申请，付款时适用安徽移动信用管理办法中规定的信誉特优供应商相关政策，在合同约定范围内，同等条件下，优先考虑A级供应商的付款需求；

2.共享行业发展趋势及产品技术信息，邀请参与产品技术发展趋势交流研讨；

3.原则上免收履约保证金等；

4.颁发优秀供应商证书，并进行公告；

5.根据产品情况，A级供应商可予以免检或降低检测频次；

6.其他经决策的管理措施。

（五）对于B级供应商可选用以下管理措施：

1.共享行业发展趋势及产品技术信息，邀请参与产品技术发展趋势交流研讨；

2.原则上可减少履约保证金的额度的50%；

3.其他经决策的管理措施。

（六）对于C级供应商可选用以下管理措施：

1.及时反馈改进意见，提供相关技术及管理方面的帮助，促使其不断提高产品质量和服务水平；

2.其他经决策的管理措施。

（七）对于D级供应商可选用以下管理措施：

1.D级供应商禁止合作期满后，首次采购时若为非招标采购项目的，经决策可扣减其综合评审得分总分0至5分(百分制)；禁止合作期满后再次合作的，经决策，可根据产品情况对其进行份额限制；

2.其他经决策的管理措施。

## 1.4 安徽移动供应商负面行为处理规则

# 一、根据乙方（供应商）负面行为给甲方（安徽移动）通信网络建设、生产运营、优质服务、企业形象造成的负面影响程度和经济损失不同，依次分为一般负面行为、严重负面行为和特别严重负面行为。

# 二、有下列情况之一者，为一般负面行为：

（一）产品质量不合格且达到合同规定质量问题负面行为标准；

（二）供应商原因造成延期交货，或存在服务人员未按合同要求及时到位、技术指导或售后服务未达到合同约定等服务问题，且对网络建设进度、网络质量或生产运营等造成影响；

（三）供应商故意修改采购文件明确列明的技术参数并进行响应，或在合同签订过程中擅自对合同实质性条款进行修改；

（四）转包、违法分包合同标的；

（五）未按照承诺使用承诺品牌、承诺参数的元器件或原材料被责任追究或导致安徽移动利益受损，或供应产品到货配置与订单配置不一致且导致安徽移动利益受损；

（六）合同履约过程中供应商无不可抗力、情势变更等合理正当理由提出解除合同/框架协议，但已积极采取措施减少对安徽移动网络建设进度、网络质量等影响；

（七）因供应商产品或供应商操作等原因造成安徽移动网络故障，达到《电信网络运行监督管理办法》（工信部电管〔2009〕187号,以下简称《监督管理办法》）定义的重大事故，或达到《中国移动全网重大通信故障定义》（以下简称《故障定义》，详见本文1.6章节）定义的故障情形。如前述事故或故障同时符合《监督管理办法》和《故障定义》的相应情形定义，则以《监督管理办法》定义的情形为准；

（八）因供应商产品或操作等原因给安徽移动造成网络安全风险事件，达到《公共互联网网络安全突发事件应急预案》（工信部网安[2017]281号，以下简称《公共互联网网络安全突发事件应急预案》）或《互联网网络安全信息通报实施办法》（工信部保[2009]156号，以下简称《互联网网络安全信息通报实施办法》）定义的一般事件或较大事件；

（九）因供应商产品或供应商操作等原因造成安徽移动生产安全事故，并达到国家《生产安全事故报告和调查处理条例》（国务院令第493号，以下简称《生产安全事故条例》）定义的一般事故级别；

（十）因供应商产品或供应商操作等原因造成安徽移动突发环境事件，并达到《突发环境事件分级标准》（国办函[2014]119号，以下简称《突发环境事件分级标准》）定义的一般（Ⅳ级）突发环境事件；

（十一）在合同履约过程中，因供应商原因发生拖欠农民工工资，引发农民工上访事件且拒绝整改；

（十二）其他经安徽移动认定为一般负面行为的。

# 三、有下列情况之一者，为严重负面行为：

（一）在采购活动中供应商以他人名义参加采购或弄虚作假，包括但不限于使用伪造变造的许可证件、检测报告，提供虚假的财务状况或者业绩，提供虚假的项目负责人或者主要技术人员简历、劳动关系证明，提供虚假的信用状况，以及与检测单位串通伪造检测结果的行为等；

（二）在采购活动中供应商相互串通或者与采购人及采购相关方串通，包括但不限于相互协商报价等实质性内容，约定中选人，约定部分供应商放弃参加采购或者中选，按照同一集团、协会、商会等组织要求协同投标，为谋取中选或者排斥特定供应商而采取联合行动，非法获知标底或评审委员会成员信息等；

（三）不按采购文件及应答文件承诺签订合同或框架协议的，包括但不限于已列入中选候选人的供应商在发布候选人公示之日后无正当理由放弃中选资格或中标通知书发出后拒绝签订合同文件以及在合同履约过程中无不可抗力、情势变更等合理正当理由不履约且拒绝整改；

（四）对采购人或其他供应商进行诋毁、恶意异议，或对其他供应商、采购人等采购活动的相关方采取威胁、欺骗等非法手段的。恶意异议行为包括但不限于捏造事实、伪造材料、以非法手段取得证明材料进行异议、首次异议受理并正式答复后，在不能提供新的有效证据情况下仍就同一问题再次进行异议，在采购人给予后续处罚提醒后，依然就同一问题继续进行异议；

（五）因供应商产品或供应商操作等原因造成安徽移动网络故障，并达到《监督管理办法》定义的特别重大事故；

（六）因供应商产品或操作等原因给安徽移动造成网络安全风险事件，达到《公共互联网网络安全突发事件应急预案》或《互联网网络安全信息通报实施办法》定义的重大事件；

（七）因供应商产品或供应商操作等原因造成安徽移动生产安全事故，并达到《生产安全事故条例》定义的较大事故；

（八）因供应商产品或供应商操作等原因造成安徽移动突发环境事件，并达到《突发环境事件分级标准》定义的较大（Ⅲ级）突发环境事件，或引起生态环境损害赔偿并达到《关于深入推进生态环境损害赔偿制度改革若干具体问题的意见》（环法规〔2025〕6号）规定的重大案件；

（八）在合同履约过程中，因供应商原因发生拖欠农民工工资，引发农民工上访事件，拒绝整改且造成较大及以上舆情（参照中国移动舆情工作管理办法）；

（九）违反合同约定的保密义务，或违反其他依法或依照商业惯例负有的保密义务，对外泄露安徽移动商业秘密；

（九）其他经安徽移动认定为严重负面行为的。

# 四、有下列情况之一者，为特别严重负面行为：

（一）司法机关认定供应商存在单位行贿行为，包括向采购人、评审委员会成员、采购代理机构、检测单位等安徽移动采购相关方及相关人员行贿或提供不正当利益；

（二）因供应商产品或供应商操作等原因造成安徽移动生产安全事故，并达到《生产安全事故条例》定义的重大事故及以上级别事故；

（三）因供应商产品或操作等原因给安徽移动造成网络安全风险事件，达到《公共互联网网络安全突发事件应急预案》或《互联网网络安全信息通报实施办法》定义的特别重大事件；

（四）因供应商产品或供应商操作等原因造成安徽移动突发环境事件，并达到《突发环境事件分级标准》定义的重大（Ⅱ级）及以上突发环境事件；

（五）与安徽移动的合作中或涉及安徽移动的行为发生严重违法违规行为，受到重大刑事处罚、重大行政处罚；

（六）其他经安徽移动认定为特别严重负面行为的。

# 五、根据乙方（供应商）负面行为分级情况和产品是否充分竞争属性不同，对发生负面行为的供应商给予所有充分竞争采购领域的产品禁止合作三年、相应产品类别禁止合作三年、扣减后续采购综合评审得分、终止剩余份额执行等追究措施。(详见附件：《安徽移动供应商负面行为责任追究措施》)。责任追究情况在中国移动采购与招标网公告。

# 六、对于禁止合作供应商自禁用期起自动进入安徽移动供应商“黑名单”，禁用期三年，禁用期满且在期限内完成整改并承诺依法合规开展业务的供应商，将其移除供应商“黑名单”。对禁用期结束时仍未完成整改的供应商，自动延长其追责期限。

# 七、处于“黑名单”的供应商，在追责相应的品类、地域范围内不具备中标或中选资格、不得新签采购合同。

# 八、乙方（供应商）因其负面行为被追究责任的，其基于合同约定应承担的违约责任仍应继续承担。对供应商负面行为的处理不替代对供应商合同或采购文件规定的法律责任追究。

# 九、甲方（安徽移动）接收供应商负面行为信息和证明材料后，将履行情况调查核实、与供应商确认、负面行为认定及处理等程序。与供应商确认时一般采用书面、会议、邮件确认等形式，供应商未在规定时限内确认且证据确凿，视为供应商确认。对于在采购寻源阶段由评审委员会认定的供应商围标串标或弄虚作假等负面行为，处理时可不再与供应商进行确认。

# 十、供应商向安徽移动采购相关方及相关人员行贿或提供不正当利益，但未经法院判决的，安徽移动各级纪检监察机构认为需进行处罚的，安徽移动有权按照供应商负面行为责任追究措施表进行相应责任追究。

# 十一、供应商人员或其他相关人员行贿或提供不正当利益的，安徽移动各级纪检监察机构认定的，三年内安徽移动有权拒绝任何供应商安排涉事人员代表其参与安徽移动采购活动；司法机关认定的或中国移动纪检监察组研判认定要求处理的，中国移动及其下属单位三年内有权拒绝任何供应商安排涉事人员代表其参与中国移动的采购活动。涉事人员禁入情况原则上应告知本人并在禁入涉及范围内进行公告。供应商代表是指作为供应商法定代表人或者委托代理人。

涉事人员在实施行为时是供应商的法定代表人、实际控制人、采购或合同文件中申报的控股个人股东/投资人的，若供应商不能提交有权机关的认定结论或相关意见，以证明涉事人员的行为与为供应商谋取交易机会或者竞争优势无关的，则按照供应商行贿行为处理，同步对个人及供应商进行追责。

# 十二、发生以下情形之一的，中国移动全集团实施供应商禁止合作联动，禁止合作期三年。

（一）供应商发生司法机关认定单位行贿行为；

（二）中国移动纪检监察组研判认定应联动处理的提供不正当利益行为；

（三）因供应商产品、操作等原因造成重大级别及以上生产安全事故；

（四）因供应商产品、操作等原因造成特别重大网络安全风险事件；

（五）因供应商产品、操作等原因造成重大及以上突发环境事件；

（六）发生涉及中国移动的严重违法违规行为受到重大刑事处罚、重大行政处罚的；

（七）其他经中国移动判定须联动处理负面行为的。

## 1.5 中国移动网络安全风险警示名单处理规则

为有效降低网络安全风险，提升供应链安全水平，推进构建尽责、诚信、自律的电信和互联网行业网络安全良性生态，中国通信企业协会通信网络安全专业委员会（以下简称通企协会）联合行业自律成员单位共同建立了电信和互联网行业网络安全风险警示企业名单自律管理制度，中国移动成为首批行业自律成员单位。通企协会组织开展风险警示名单管理。

电信和互联网行业网络安全风险警示企业名单是指将违反网络安全相关法律、法规、规章、政策及可能对网络基础设施造成重大网络安全风险的供应商，列入风险警示名单，督促供应商落实网络安全主体责任，促进产品高质量供给，规范安全服务行为。

### 一、网络安全风险警示名单的认定与分级标准

风险警示名单采取分级管理方式，按照情节严重程度从高到低分为红色警示名单和黄色警示名单。

#### （一）红色警示名单

对符合下列情形之一的供应商，纳入红色警示名单：

1.违反网络安全有关法律法规、部门规章或者政策文件，受到电信主管部门等有关机关行政处罚、刑事制裁的：

2.网络安全责任落实不到位，导致电信行业关键信息基础设施发生重大网络安全事件或者为网络基础设施带来重大安全威胁，且拒不改正的：

3.其他严重危害电信和互联网行业网络安全的。

#### （二）黄色警示名单

对符合下列情形之一的网络产品和服务提供者，纳入黄色警示名单。

1.受到电信主管部门等行政机关约谈、通报，或者受信息通信网络安全响应中心、工业和信息化部网络安全威胁和漏洞信息共享平台等有关机构单位网络安全通报的；

2.网络产品、服务存在严重安全缺陷、漏洞等风险时，未及时采取有效补救措施，未按规定告知用户并向主管部门报告的，或者违规公开发布网络安全漏洞的，并经主管部门认定情节较严重或者造成重大影响的；

3.未经行业主管部门、运营者授权，对基础电信网络实施漏洞探测、渗透性测试等危害基础电信网络安全行为的；

4.在提供产品和服务时，制作、设置、传播和利用恶意程序，尚未改正的；

5.在提供产品和服务时，未按约定为其产品、服务持续提供安全维护的；

6.落实网络安全责任不到位，导致网络产品和服务使用者的信息被泄露、造成重大网络安全事件、带来重大网络安全威胁的；

7.其他危害电信和互联网行业网络安全的。

### 二、网络安全风险警示名单的责任追究措施

对于列入风险警示名单的供应商，通企协会可按照相关规则取消其通信网络安全服务能力评定证书，或者限制其申请网络安全服务能力评定等，同时可建议电信主管部门对相关供应商实施重点监督。

对于列入风险警示名单的供应商，按照通企协会给成员单位提出的处理措施建议，结合产品是否充分竞争属性，中国移动将采取相应限制措施，包括但不限于禁止合作、终止合同、停服排查、暂停部分或者全部采购、扣减后续采购综合评审得分或后评估得分、扣减分配份额、取消联合共建项目资格、预警、约谈等追究措施。

### 三、其他

在网络安全风险警示名单过程中，供应商可就其中存在的不实、不合规等情况按照既定方式进行申诉。
